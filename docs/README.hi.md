# मूल्य मॉनिटर

> macOS के लिए स्थानीय टूल जो चुनी हुई दुकानों के मूल्य और स्टॉक तथा मेनू बार में WOYAO API बैलेंस और हाल का उपयोग दिखाता है।

[简体中文](../README.md) · [English](README.en.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · **हिन्दी**

## सुविधाएँ

- मिलते-जुलते उत्पादों को समूहित कर कम से अधिक मूल्य क्रम में दिखाता है।
- हर मिनट दुकानों की जाँच कर नए स्टॉक या पुनः उपलब्धता की macOS आवाज़ सूचना देता है।
- वर्तमान WOYAO बैलेंस को सीधे मेनू बार में दिखाता है।
- हर घंटे उपयोग अपडेट कर बैलेंस, उपयोग की गई कोटा और आज की लागत बोलकर बताता है।
- हाल की दस कॉल के मॉडल, लागत, टोकन और समय दिखाता है।

## त्वरित शुरुआत

1. [Releases](../../releases/latest) से `PriceMonitor-v1.4-macOS-arm64.zip` डाउनलोड करें, अनज़िप करें और ऐप को Applications में रखें।
2. ऐप को एक बार खोलें। लॉगिन पर चलाने के लिए `LaunchAgent.plist` उपयोगकर्ता टेम्पलेट स्थापित करें।
3. **WOYAO उपयोग** खोलें, API Key चिपकाएँ और **Documents में सहेजें और पढ़ें** चुनें।

## गोपनीयता

स्टोर डेटा सार्वजनिक API से पढ़ा जाता है। WOYAO Key केवल `Documents/价格监控/woyao-api-key.txt` में रखी जाती है; यह Git, सामान्य लॉग या ब्राउज़र डेटा में नहीं लिखी जाती। इस सादे टेक्स्ट फ़ाइल को सार्वजनिक क्लाउड में सिंक न करें।

## बिल्ड और लाइसेंस

macOS, Xcode Command Line Tools और Swift 6 आवश्यक हैं। `价格监控.app` बनाने के लिए `./build_app.sh` चलाएँ।
