# Монитор цен

> Локальная утилита macOS для просмотра цен и наличия в выбранных магазинах, а также баланса и недавнего использования API WOYAO в строке меню.

[简体中文](../README.md) · [English](README.en.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · **Русский**

## Возможности

- Группирует сопоставимые товары и сортирует их по возрастанию цены.
- Проверяет магазины каждую минуту и голосом сообщает о новых товарах или пополнении.
- Показывает текущий баланс WOYAO прямо в строке меню.
- Каждый час обновляет использование и озвучивает баланс, израсходованную квоту и стоимость за день.
- Показывает последние десять вызовов: модель, стоимость, токены и время.

## Быстрый старт

1. Скачайте `PriceMonitor-v1.4-macOS-arm64.zip` со страницы [Releases](../../releases/latest), распакуйте архив и переместите приложение в Applications.
2. Один раз откройте приложение. Для запуска при входе установите пользовательский шаблон `LaunchAgent.plist`.
3. Откройте **Использование WOYAO**, вставьте API Key и выберите **Сохранить в Documents и прочитать**.

## Конфиденциальность

Данные магазинов читаются из публичных API. Ключ WOYAO хранится только в `Documents/价格监控/woyao-api-key.txt`; он не записывается в Git, обычные журналы или данные браузера. Не синхронизируйте этот текстовый файл с публичным облаком.

## Сборка и лицензия

Требуются macOS, Xcode Command Line Tools и Swift 6. Выполните `./build_app.sh`, чтобы создать `价格监控.app`.
