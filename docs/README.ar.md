# مراقب الأسعار

> أداة محلية لنظام macOS لمتابعة أسعار ومخزون المتاجر المحددة، ورصيد واستخدام واجهة WOYAO API في شريط القوائم.

[简体中文](../README.md) · [English](README.en.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · **العربية**

## الميزات

- تجمع المنتجات المتشابهة وترتبها من الأقل سعراً إلى الأعلى.
- تفحص المتاجر كل دقيقة وتعلن صوتياً عن المنتجات الجديدة أو عودة المخزون.
- تعرض رصيد WOYAO الحالي مباشرة في شريط القوائم.
- تحدث الاستخدام كل ساعة وتعلن الرصيد والحصة المستخدمة وتكلفة اليوم.
- تعرض آخر عشر استدعاءات مع النموذج والتكلفة والرموز والوقت.

## بدء سريع

1. نزّل `PriceMonitor-v1.4-macOS-arm64.zip` من [Releases](../../releases/latest)، وفك الضغط ثم انقل التطبيق إلى Applications.
2. افتح التطبيق مرة واحدة. للتشغيل عند تسجيل الدخول، ثبّت قالب المستخدم `LaunchAgent.plist`.
3. افتح **استخدام WOYAO**، والصق API Key واختر **الحفظ في Documents والقراءة**.

## الخصوصية

تُقرأ بيانات المتاجر من واجهات API عامة. يُخزن مفتاح WOYAO فقط في `Documents/价格监控/woyao-api-key.txt`، ولا يكتب في Git أو السجلات العادية أو بيانات المتصفح. لا تزامن هذا الملف النصي مع مساحة تخزين عامة.

## البناء والترخيص

يتطلب macOS وXcode Command Line Tools وSwift 6. شغّل `./build_app.sh` لإنشاء `价格监控.app`.
