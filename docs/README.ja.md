## できること

価格モニターは、頻繁に確認する二種類の情報をひとつのローカルアプリにまとめます。指定ショップの商品価格・在庫と、WOYAO API の残高・利用状況です。macOS ログイン時に起動し、メニューバーには WOYAO の現在残高だけを表示します。

注文や決済は行いません。商品を選んだ場合は、既定のブラウザで該当する購入ページを開くだけです。

## 主な機能

- 類似商品をグループ化し、各グループを価格の安い順に表示します。
- ショップを毎分確認し、新規在庫を macOS 音声で通知します。
- WOYAO の現在残高をメニューバーに直接表示します。
- WOYAO を毎時更新し、残高・使用済み枠・当日コストを音声で読み上げます。
- 直近 10 件の呼び出しについて、モデル、費用、Token、時刻を表示します。
- 数値・文字列・null の揺れを許容し、利用履歴の問題で残高表示が止まらないようにします。

## クイックスタート

1. [Releases](../../releases/latest) から `PriceMonitor-v1.4-macOS-arm64.zip` をダウンロードし、展開して「アプリケーション」へ移動します。
2. 一度アプリを開きます。ログイン時に自動起動したい場合は、`LaunchAgent.plist` のユーザー用テンプレートを導入します。
3. **WOYAO 用量** を開き、API Key を貼り付けて **保存到文档并读取** を選択します。
4. Key は `Documents/价格监控/woyao-api-key.txt` のみに保存されます。ショップ監視にはログイン不要です。

## 仕組み

公開ショップ API は価格比較・新規在庫の音声通知・商品リンクに利用されます。WOYAO の利用 API はメニューバー残高、毎時の音声通知、直近利用一覧に利用されます。主画像はコンセプトイラストであり、実際の画面やアカウントデータではありません。

## プライバシーと範囲

- ショップ情報は公開 API から読み取ります。
- WOYAO API Key はユーザーが手動で入力し、現在の macOS ユーザーだけが読める Documents 内のファイルに保存されます。
- Key はこのリポジトリ、通常ログ、ブラウザデータには書き込みません。
- Release には Key、残高、利用履歴、Cookie、クラッシュレポート、ログイン情報は含めません。

Documents 内の Key ファイルは平文です。公開クラウドへの同期や Git への追加はしないでください。

## ビルド

macOS、Xcode Command Line Tools、Swift 6 が必要です。

```zsh
./build_app.sh
```

`价格监控.app` が生成されます。ローカルのビルド成果物は Git から除外されています。配布には Release 資産を使用してください。

## ダウンロードと検証

各 Release には arm64 macOS アーカイブと `.sha256` ファイルが含まれます。以下で検証できます。

```zsh
shasum -a 256 PriceMonitor-v1.4-macOS-arm64.zip
```

同じ Release の SHA-256 ファイルと結果を比較してください。

## 既知の制限

- Apple Silicon（arm64）のみをビルド・検証しています。
- ローカル署名済みですが Apple 公証はしていません。初回起動時には Finder で Control クリックして「開く」が必要になる場合があります。
